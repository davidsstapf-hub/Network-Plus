# N10-009 Curriculum Map

The official CompTIA Network+ N10-009 objectives remain the source of truth.

## Domains

| Domain | Weight | Coverage |
| --- | ---: | --- |
| 1.0 Networking Concepts | 23% | OSI model, appliances, cloud, ports, media, topologies, IPv4, modern network environments |
| 2.0 Network Implementation | 20% | Routing, switching, wireless, physical installation |
| 3.0 Network Operations | 19% | Documentation, monitoring, disaster recovery, services, remote access |
| 4.0 Network Security | 14% | Security concepts, attacks, hardening, defenses |
| 5.0 Network Troubleshooting | 24% | Methodology, physical issues, services, performance, tools |

## Learning Loop

Every numbered objective `1.1-5.5` includes:

1. Core lesson
2. Worked scenario
3. Flashcard deck
4. Five-question coached check
5. Ten-question section quiz
6. Tier checkpoint representation
7. Final practice exam representation

The dedicated Subnetting Lab is supplemental practice. It reinforces objective 1.7 skills but is excluded from official domain weighting and final-exam weighting.
