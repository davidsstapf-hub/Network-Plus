# Beginner Readiness Audit

This audit defines the launch standard for taking a true beginner from zero to Network+ readiness.

## Rubric

Each numbered N10-009 objective must satisfy all five checks before launch:

- Defines required vocabulary before using it.
- Explains why the concept matters in a real network.
- Includes a concrete workplace example.
- Includes a worked scenario, decision path, or practice task.
- Connects to likely exam reasoning without copying CompTIA questions, dumps, or proprietary courseware.

## Current Product Additions

- Dashboard readiness signals now track beginner foundation, subnetting confidence, checkpoint readiness, and final exam readiness.
- Weak scored objectives now map back to remediation activities.
- Every numbered objective now has an in-lesson beginner bridge with vocabulary, why-it-matters context, a workplace example, and a mental model.
- Objectives previously marked weak now have an instructor-pass expansion with plain-language teaching, workplace examples, beginner traps, exam reasoning, and focused mini-drills.
- Subnetting practice now includes network/broadcast, CIDR-to-mask, mask-to-CIDR, required-host sizing, VLSM allocation, and binary octet drills.

## Launch Gate

Human learner validation is still required. Recruit at least three learners per tier, including at least one true beginner, and record confusing explanations, difficulty jumps, navigation friction, device/browser, completion outcome, and accessibility issues in `docs/VALIDATION_LOG.md`.
